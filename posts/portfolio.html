1. 개요

아래는 현재 실제로 보유 중인 종목을 그대로 옮긴 스냅샷이다. 매수 시점별 전체 거래 내역을 복원하지 못해, 매입가·매입환율은 현재 보유 수량 기준 평균 취득 정보로 기록했다. 시세와 원/달러·원/엔 환율은 야후 파이낸스(Yahoo Finance) 기준이며, GitHub Actions가 평일 하루 한 번 자동으로 가져와 이 페이지가 읽는 data/portfolio.json을 갱신한다. 브라우저가 야후 파이낸스를 직접 호출하지 않으므로, 방문 시점의 값은 최근 자동 갱신 시점 기준이며 장중 실시간은 아니다.

※ 투자 조언이 아닌 개인 기록의 공개이며, 실제 매매 판단의 근거로 삼지 말 것.

4. 갱신 방식·유의사항

시세·환율은 Yahoo Finance에서 가져온다. GitHub Actions 스케줄러가 평일 한국시간 06:30경(미국 정규장 마감 후) 실행되어 data/holdings.json에 기록된 보유 정보와 그날의 시세·환율을 합산한 뒤 data/portfolio.json을 새로 커밋한다. 매매(추가매수·매도)가 발생하면 data/holdings.json을 직접 수정한다 — 자동화 대상은 시세뿐이고 보유 정보 자체는 수동으로 관리한다.

환차익 미포함은 매입 시점 대비 현재가의 현지 통화 기준 가격 변동만 반영한 수익률이고(원/달러·원/엔 환율은 매입 시점 그대로 고정), 환차익 포함은 여기에 매입 시점 이후 환율 변동분까지 더한 원화 환산 실수익률이다. 상단 토글로 전환할 수 있으며 기본값은 환차익 미포함이다.

시세 조회가 실패하면 워크플로가 커밋을 건너뛰므로, 이 경우 위 데이터는 마지막으로 성공한 날짜의 값 그대로 남는다.
